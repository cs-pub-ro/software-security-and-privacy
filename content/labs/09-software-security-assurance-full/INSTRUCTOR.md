# Instructor Notes: Session 09 --- Software Security Assurance

Local exercises, no deployment.

The point of the session is that the three kinds of flaw need three kinds of attention: the compiler warning (aplusplus, weird), the analyser (hidden-bugs), and the careful reading of an edge case (this-is-not-possible).
Run the analysers together on `hidden-bugs.c` and compare what each one catches; the gap is the lesson.

The annotated solution files give away the answers, so they stay in the full half only.
