# Session 09: Software Security Assurance

The reference half of the [software security assurance lab](../09-software-security-assurance-live/README.md).

Each task directory holds the annotated version of its program, with every bug or undefined-behaviour point marked and explained.
These are local reading-and-analysis exercises; there is nothing to deploy.
