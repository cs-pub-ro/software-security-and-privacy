# Exercise: Can't Find Me

**Tools:** SSH, find

## Goal

Find the flag, hidden somewhere on the filesystem under a name you have to search for.

## Background

The flag lives in a file whose name contains a particular word, somewhere under a directory the challenge tells you about.
It will not be in front of you; you have to look.

## Your Task

1. Connect over SSH to the address listed on the CTF platform.
1. Search the indicated directory for a file whose name contains the given word.
1. Read it.

## Check Your Work

The file contains a string of the form `SSP{...}`.
Be ready to say which tool you used to find it and why.
