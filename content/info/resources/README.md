## Virtual Machine

You can use any x86-64 Linux environment (native install, virtual machine, a container) for the class.
Most exploitation challenges are 32-bit x86 binaries, so an ARM machine needs an emulated x86 virtual machine for those sessions.

We provide a Linux virtual machine with all the tools installed, built from the [`vms/`](https://github.com/cs-pub-ro/software-security-and-privacy/tree/master/vms) directory of the repository.
The download links are announced on Moodle.
